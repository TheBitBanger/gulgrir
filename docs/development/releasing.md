# Releasing

Pushing a tag publishes an image to `ghcr.io/thebitbanger/gulgrir`.

| Tag      | Branch it must be on | Image tags published   |
| -------- | -------------------- | ---------------------- |
| `vX.Y.Z` | `dev`                | `dev`, `vX.Y.Z`        |
| `vX.Y`   | `master`             | `latest`, `vX.Y`       |

Only the dev channel has releases so far.
