# Accounts requirements

| ID     | Need                                                                                                     | Why                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| ACC-1  | Several people need to share one instance, each seeing and managing only their own data.                 | So a household or group of friends can share one install.                              |
| ACC-2  | An administrator needs to manage instance settings and create users from inside the product.             | Running the instance shouldn't need developer tooling.                                  |
| ACC-3  | Sign-in needs only to keep users apart, with the basic security usual for hobbyist self-hosted software. | The instance is not meant to face the internet; it sits behind a VPN or similar access layer. |
