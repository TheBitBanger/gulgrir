# Import requirements

| ID    | Need                                                                                                                                                         | Why                                                                                 |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| IMP-1 | A user needs to bring in what they already have from other services, starting with the \*arr stack. Later sources include Goodreads, MyAnimeList, Trakt, media servers and game stores. | Starting out shouldn't mean re-entering years of history.                           |
| IMP-2 | Sources need to be added one at a time, each proven before the next.                                                                                         | A source is only worth having if its data is trustworthy.                           |
| IMP-3 | A user with notes or spreadsheets needs to import a flat file and confirm the matches.                                                                        | Users without other services can migrate too.                                       |
| IMP-4 | Connected sources need to keep feeding gulgrir after the first import, one way only.                                                                         | The user shouldn't keep two lists by hand. Gulgrir is authoritative and never writes back. |
