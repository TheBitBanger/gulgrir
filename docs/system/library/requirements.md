# Library requirements

| ID    | Need                                                                                                                                                              | Why                                                                                                   |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| LIB-1 | A user needs to track books, films, TV shows, games, music, anime, manga and light novels.                                                                         | Their backlog spans all of these.                                                                      |
| LIB-2 | Adding a new kind of thing, such as comics, podcasts or board games, needs to be cheap. Until a kind is supported, it can be tracked as a generic item.            | The goal is to track almost anything; each kind gets its own metadata once a source is researched.    |
| LIB-3 | A user needs items that no external source knows about, like projects and custom entries.                                                                          | Non-media work goes through the same flow.                                                             |
| LIB-4 | A user needs to record a small set of personal data on an item: rating or tier, short notes, and which format or platform they own it on. Long-form reviews are out. | The library shows their experience, not just catalog facts. Reviews belong on a blog.                 |
| LIB-5 | A user needs personal tags on any item, projects included.                                                                                                         | For distinctions the catalog doesn't make, like "educational" vs "fantasy" books.                      |
| LIB-6 | A user needs to search, sort and filter the library from different angles, and save filters to reuse.                                                              | The library is a search and categorization tool, and finding the next thing shouldn't need hand-made lists. |
| LIB-7 | A user needs to group items from different media into one collection, such as a franchise or universe.                                                             | Resident Evil spans games, films and books. Single-medium tools can't do this, and it's a key differentiator. |
| LIB-8 | A user needs each work to appear only once in their library.                                                                                                      | Duplicates skew counts, selections and time.                                                           |
