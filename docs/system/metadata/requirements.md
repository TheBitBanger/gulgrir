# Metadata requirements

| ID    | Need                                                                                                                                         | Why                                                                                                   |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| MET-1 | When adding an item, a user needs to find the right real-world work and have its metadata filled in, without typing details.                 | Entering metadata by hand doesn't scale to a large backlog. This is the current system's biggest gap. |
| MET-2 | When a match is ambiguous, the user needs to choose it; the system never guesses silently.                                                   | A wrong match corrupts everything built on top of it.                                                  |
| MET-3 | Metadata needs to stay current on its own, and a user needs to refresh any single item immediately.                                          | So the library doesn't go stale.                                                                       |
| MET-4 | The library needs to work fully without metadata providers. Providers only add data.                                                         | Providers are outside our control. They can be slow, down, or rate-limited.                           |
| MET-5 | A user needs to correct or override fetched metadata.                                                                                         | Providers are sometimes wrong or incomplete.                                                           |
| MET-6 | A user needs to explore works related through metadata, like everything by a director, author or band, and works in release order.           | To find more of what they enjoyed and to consume series chronologically.                              |
| MET-7 | The data needs to be complete and correct, whichever provider supplies it.                                                                    | The user cares about the data, not the source.                                                         |
| MET-8 | An administrator needs to supply the credentials providers require, such as API keys.                                                        | The best sources often need a key that each instance registers itself.                                 |
