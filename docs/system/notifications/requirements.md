# Notifications requirements

| ID    | Need                                                                                                                                                                                        | Why                                                                                                                         |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| NOT-1 | A user needs new installments of what they follow (an album from a favorite band, a new volume, a new season) to show up in one place in gulgrir, from any source that can detect them. | Serialized works release at irregular times, and following 50+ creators on social media doesn't work. The \*arr stack already detects some releases. |
| NOT-2 | A user needs reminders to revisit items, by date or on a schedule, under rules they choose, like favorites or anything above a given rating.                                                 | Favorites otherwise get buried under the backlog, and each person's rules differ.                                           |
| NOT-3 | A user needs notifications on the channel they already watch: in-app, email, chat apps or self-hosted push.                                                                                 | Alerts should reach them where they already are.                                                                            |
