# Selection requirements

Selection is an aid to choosing what to consume next. It never decides on its own.

| ID    | Need                                                                                                                                         | Why                                                                                         |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| SEL-1 | A user needs the system to suggest the next item from a set, at random or weighted by things like time spent, time since last touched, or rating. | Avoids decision paralysis on a large backlog, especially when no time has been logged yet. |
| SEL-2 | A user needs to run a selection on a saved filter or on items they picked by hand, and roll again until a suggestion fits.                    | The suggestion is a prompt, not a commitment. The user starts the item when they choose.   |
