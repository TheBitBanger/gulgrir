# Time tracking requirements

Time tracking is the second-largest part of gulgrir, after the library and metadata. It is
how the user rotates between items in practice: each block of the day (office work, personal
work, leisure) gets a goal, and once the goal is met, the next item takes its place.

| ID    | Need                                                                                                                              | Why                                                                                    |
| ----- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| TIM-1 | A user needs to record time spent on an item, live or after the fact.                                                             | To see where their time actually goes.                                                 |
| TIM-2 | A user needs to arrange items into groups of their own, nested if needed, and see time add up across them.                         | Each person splits their life differently, for example work vs play, and wants to see the split. |
| TIM-3 | A user needs time goals per item or group that tell them when they've done enough.                                                | It tells them when to rotate to the next item.                                         |
| TIM-4 | A user needs to see their time over recent days and weeks, with averages.                                                         | To check whether they're consistent, which matters most for projects and work.        |
| TIM-5 | A user needs one-step access, from anywhere in the product, to their goals, frequently used filters and pinned items, and to start or stop a timer. | So they don't have to remember what they're working on or navigate to find it.         |
